## Issue #32
`import datawrangler` crashed on Windows: `config.ini` had
`homedir = os.getenv('HOME')`, which is `None` on Windows (Windows uses
`USERPROFILE`), so `datadir` evaluated `os.path.join(None, ...)` ->
`TypeError` at import time (`configurator.py:85`).

## Changes (commit 5f0a611 + follow-up)
- `datawrangler/core/config.ini`: `homedir = os.path.expanduser('~')` (cross-platform).
- `tests/wrangler/test_core.py::test_import_without_home_env`: real-subprocess
  regression test — imports datawrangler with HOME/USERPROFILE stripped from env
  (reproduces the Windows condition on any platform; the bug is import-time only,
  so an in-process test can't catch it).
- `setup.py`: `long_description` = contents of `README.rst` (was a bare RTD link);
  `long_description_content_type` already `text/x-rst`; README.rst already in MANIFEST.in.
- Version bumped to **0.5.1** in `setup.py` AND the fallback literal in
  `datawrangler/core/configurator.py` (metadata is the single source of truth per issue #29,
  but the source-checkout fallback must be kept in sync).
- `HISTORY.rst`: added 0.5.1 entry.
- Doc references to `os.getenv('HOME')` updated in `CLAUDE.md` and `datawrangler/core/AGENTS.md`.
