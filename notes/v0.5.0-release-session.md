## What shipped in 0.5.0

### Headline bug fix — remote caching
`io/extension_handler.get_extension()` now strips URL query strings/fragments. Previously URLs like
`.../minipedia.npz?dl=1` (Dropbox/Drive, incl. the built-in corpora) cached as `<hash>.npz?dl=1` and then
failed to reload (`ValueError: Unknown datatype: npz?dl=1`), silently re-downloading. Root-caused, fixed,
regression-tested.

### Four tracked issues resolved
- **#30 pandas 3.0**: type detection used pandas' internal `__module__` strings, which pandas 3.0 flattened
  (`pandas.core.frame` → `pandas`). Switched `is_dataframe` / `is_multiindex_dataframe` / `io.panda_handler`
  to `isinstance`; dropped removed `DataFrame.backfill`/`.pad` from `util.dataframe_like`. Verified in an
  isolated **pandas 3.0.0 / py3.12** venv (issue repro passes; 30/30 core tests) AND pandas 2.3.3.
- **#29 version drift**: `__version__` now derives from `importlib.metadata` (single source = setup.py), with a
  literal fallback only for un-installed source checkouts. Also fixed the stale/broken `[bumpversion]` config in
  setup.cfg (it pointed at `datawrangler/__init__.py`, which doesn't define `__version__` — the root cause of the drift).
- **#8 demo GIF**: `scripts/make_demo_gif.py` renders `docs/images/demo.gif` from REAL calls — a 60M-value Polars
  sort (~8× faster than pandas, measured live), sentence-embedding semantic similarity, `@funnel`, and ML imputation.
- **#5 tutorials**: filled the whole issue checklist across 7 notebooks; all execute cleanly (0 error outputs);
  fixed 3 pre-existing NameErrors.

### Other correctness fixes (from a full package audit)
- `core.configurator.apply_defaults` no longer `KeyError`s for names absent from config.ini (had broken sklearn TSNE/MDS/Isomap).
- `decorate.apply_stacked` no longer crashes on `return_model=True` with unstacked input.
- Removed a dead npz-unwrap branch in `io.load`; fixed two missing f-string prefixes in `zoo.text`.
- Deleted dead duplicate modules `zoo/text_lazy.py` and `zoo/text_original.py`.
- HuggingFace corpora must use `namespace/name` ids now (`datasets` >= 4): `get_corpus` default → `wikimedia/wikipedia`
  (config `20231101.en`); test corpus `cbt` → `cam-cst/cbt` (verified byte-identical: 108 docs).

### Dependencies / quality
- Declared **pyarrow** in requirements.txt (polars↔pandas conversion needs it — surfaced by the clean pandas-3.0 env).
- **flake8: 912 → 0** (set explicit `max-line-length = 120`; removed genuinely-unused imports, `type==`→`is`,
  bare-except→`except Exception`; `# noqa` only for eval/exec/side-effect/lazy imports).
- **Sphinx docs: warning-free** `sphinx -E -a -W` build (fixed docstrings' `*args`/field-lists, RST, notebook
  ipython2→ipython3 lexer + heading levels, added API stubs incl. `datawrangler.zoo.polars_dataframe`).
- Added hierarchical `AGENTS.md` files, refreshed `CLAUDE.md`, added `scripts/verify_functions.py` smoke test.
- Tests: full suite **61 passed / 0 failed** (added 16 tests incl. #29/#30 regressions).
